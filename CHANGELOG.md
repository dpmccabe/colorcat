# Changelog

## 0.1.0

First release: `palette()` and `min_distance()`, `background="white"|"black"`,
`min_contrast` (WCAG contrast with the background, default 3), `restart_count`, `fixed`, `exclude`, `color_format`, `cvd` (protan, deutan and/or tritan) and `seed`
arguments, and a `colorcat` command.
